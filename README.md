# ⚡ PixPDF

موقع ويب عصري متعدد الصفحات يجمع أدوات مفيدة تعمل داخل المتصفح.

## مساحة العمل

الصفحة الرئيسية هي مساحة عمل موحدة:
- اسحب صور وملفات PDF معًا
- شاهد معاينة مصغرة لكل عنصر
- رتب البطاقات بالسحب والإفلات
- شاهد إحصائيات مباشرة
- صدّر كل شيء كملف PDF واحد

## الأدوات

- صور إلى PDF، PDF إلى صور، استخراج النصوص OCR، نص إلى PDF
- دمج، تقسيم، تدوير وحذف صفحات PDF، علامة مائية
- تغيير مقاس الصور، ضغط الصور
- مولد كلمات مرور، عدّاد نصوص، QR عادي و QR لـ Wi-Fi

## المميزات

بحث فوري، شعار متحرك، خلفية تفاعلية، بطاقات ثلاثية الأبعاد، انتقالات صفحات، وضع فاتح/داكن، تدرجات موحدة، صفحة "كيف يعمل"، إحصائيات، رسائل خطأ مفيدة، سحب وإفلات.

## الخصوصية

جميع العمليات تتم داخل متصفح المستخدم، بدون رفع الملفات إلى أي سيرفر.

## التشغيل

افتح `index.html` مباشرة في المتصفح.
